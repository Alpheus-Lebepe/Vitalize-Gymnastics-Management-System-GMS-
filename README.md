# Vitalize-Gymnastics-Management-System-GMS-

This is a PHP-based Gymnastics Management System for a
fitness platform called "Vitalize". This system allows gymnastics coaches to manage
training programs and allow gymnasts to enrol in sessions and track their fitness and
skill development over time.

The system provide functionalities to add, edit, delete, and view gymnastics
programs. It also track gymnast enrolments, monitor their attendance, and
calculate individual and group progress toward fitness or skill goals.
